# ReadmitIQ Project Story: Stage Notebook Index

This directory contains the sequential, self-contained, slide-ready Jupyter notebooks that walk through the ReadmitIQ clinical readmission decision support platform from initial framing to deployment.

## Execution Order

1. **[stage1.ipynb](stage1.ipynb)**: Problem Framing, Clinical Economics, and System Architecture
2. **[stage2.ipynb](stage2.ipynb)**: Data Cleaning, Preprocessing, and Patient-Level Splitting
3. **[stage3.ipynb](stage3.ipynb)**: RAG Feature Engineering with Vector Retrieval (ChromaDB / FAISS)
4. **[stage4.ipynb](stage4.ipynb)**: Classical Machine Learning Models (Logistic Regression & Random Forest)
5. **[stage5.ipynb](stage5.ipynb)**: Transformer-Based Model & Clinical Note Embeddings
6. **[stage6.ipynb](stage6.ipynb)**: Model Evaluation, Explainability (SHAP), Fairness & Drift Audit
7. **[stage7.ipynb](stage7.ipynb)**: Full-Stack Application, Deployment Verification, and API Contracts

## Directory Structure

- `notebooks/stages/`: Executable Jupyter notebooks and helper module (`_stage_helpers.py`).
- `reports/stages/`: Fully executed HTML exports generated via `jupyter nbconvert`.
- `reports/stages/figures/`: High-resolution figures (150 DPI) generated by each stage.
- `models/stages/`: New intermediate stage-specific artifacts (isolated from frozen models).
